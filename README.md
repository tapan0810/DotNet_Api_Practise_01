# DotNet API Practice 01

ASP.NET Core Web API practice project focused on fundamentals of RESTful API development and C# backend programming.

## Focus
- ASP.NET Core Web API
- Controllers and routing
- Dependency Injection
- RESTful HTTP methods
- C# and asynchronous programming

## Running
```bash
dotnet restore
dotnet run
```

Open the API endpoint shown by the application at startup.
